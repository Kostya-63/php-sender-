## Why

Первый этап реализовал генерацию PDF. Теперь нужно реализовать реальную отправку отчётов через 3 канала: VK, Max и Email. Это завершает основной функционал студенческого портала — от создания отчёта до его доставки получателю.

## What Changes

- Реализация VK-отправки через Bot API (загрузка документа + отправка в чат)
- Реализация Max-отправки через API (POST /uploads + POST /messages с file-вложением)
- Реализация Email-отправки через SMTP с PHPMailer (PDF как attachment)
- Интерфейс выбора получателя (выпадающий список из БД портала)
- Интерфейс выбора канала (VK / Max / Email)
- Конечный результат — PDF реально появляется в VK-чате / Max-диалоге / email-ящике

## Capabilities

### New Capabilities
- `vk-sender`: Отправка PDF-документа через VK Bot API (загрузка файла + отправка в чат)
- `max-sender`: Отправка PDF-документа через Max API (загрузка файла + отправка с вложением)
- `email-sender`: Отправка PDF-документа через SMTP (PHPMailer + attachment)
- `recipient-selection`: Выбор получателя из списка (преподаватели, кураторы)

### Modified Capabilities
- `pdf-creator`: Добавлена кнопка «Отправить отчёт» с выбором канала и получателя

## Impact

- **Зависимости**: `phpmailer/phpmailer` для Email
- **Конфигурация**: `config/messengers.php` с токенами VK, Max, SMTP
- **API**: POST /api/send — отправка с параметрами channel, recipient_id
- **Фронтенд**: Модальное окно выбора получателя и канала
- **БД**: Таблица recipients (получатели из портала)
