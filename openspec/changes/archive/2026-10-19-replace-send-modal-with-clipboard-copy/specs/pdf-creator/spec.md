## REMOVED Requirements

### Requirement: Система отправляет PDF в мессенджер

Система MUST уметь отправлять сгенерированный PDF-документ в мессенджер (реализация мессенджера определяется на втором этапе).

**Reason**: Функционал отправки через модальное окно заменён на копирование в буфер обмена. Модальное окно, выбор канала и ввод адресата удалены.
**Migration**: Вместо отправки — использовать кнопку «Копировать в буфер» для помещения PDF в буфер обмена.

### Requirement: Пользователь видит интерфейс с двумя кнопками

Система MUST предоставлять веб-интерфейс с двумя кнопками: «Создать документ» и «Отправить документ».

**Reason**: Кнопка «Отправить отчёт» заменена на «Копировать в буфер».
**Migration**: Кнопка «Отправить отчёт» переименована в «Копировать в буфер».

## ADDED Requirements

### Requirement: Система копирует PDF в буфер обмена

Система MUST уметь копировать сгенерированный PDF-файл в буфер обмена браузера по нажатию кнопки «Копировать в буфер» без использования модальных окон.

#### Scenario: Копирование PDF в буфер по нажатию кнопки

- **WHEN** документ создан и пользователь нажимает кнопку «Копировать в буфер»
- **THEN** система копирует бинарные данные PDF в буфер обмена как файл с MIME type `application/pdf`

#### Scenario: Успешная обратная связь

- **WHEN** PDF успешно скопирован в буфер
- **THEN** система показывает зелёное уведомление «Документ скопирован в буфер обмена»

#### Scenario: Ошибка копирования

- **WHEN** копирование в буфер не удалось (браузер не поддерживает Clipboard API или пользователь отклонил запрос)
- **THEN** система показывает красное уведомление с сообщением об ошибке

#### Scenario: Кнопка неактивна без документа

- **WHEN** документ не создан
- **THEN** кнопка «Копировать в буфер» неактивна
