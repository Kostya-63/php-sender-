## ADDED Requirements

### Requirement: Отправка PDF через VK Bot API
Система MUST уметь загружать PDF-файл в VK и отправлять его в чат от имени бота.

#### Scenario: Загрузка PDF в VK
- **WHEN** пользователь выбирает VK как канал отправки
- **THEN** система вызывает POST /messages/getUploadServer для получения upload_url

#### Scenario: Отправка PDF в чат VK
- **WHEN** PDF загружен на uploads-сервер VK
- **THEN** система вызывает POST /messages/send с document attachment в указанный chat_id

#### Scenario: Ошибка загрузки VK
- **WHEN** загрузка PDF на сервер VK не удалась
- **THEN** система показывает сообщение об ошибке и не отправляет сообщение

### Requirement: Отправка PDF через Max API
Система MUST уметь загружать PDF-файл в Max и отправлять его как вложение.

#### Scenario: Загрузка PDF в Max
- **WHEN** пользователь выбирает Max как канал отправки
- **THEN** система вызывает POST /uploads?type=file для получения upload_url и token

#### Scenario: Отправка PDF в Max
- **WHEN** PDF загружен на сервер Max
- **THEN** система делает паузу 2 секунды и вызывает POST /messages с attachment payload.token

#### Scenario: Ошибка обработки файла Max
- **WHEN** сервер Max возвращает "attachment.not.ready"
- **THEN** система повторяет попытку с увеличенным интервалом (до 3 попыток)

### Requirement: Отправка PDF через Email
Система MUST уметь отправлять PDF-файл как вложение через SMTP.

#### Scenario: Отправка email с PDF
- **WHEN** пользователь выбирает Email как канал отправки
- **THEN** система создаёт HTML-письмо с PDF-attachment и отправляет через SMTP

#### Scenario: Ошибка SMTP
- **WHEN** SMTP-соединение не установлено или аутентификация не пройдена
- **THEN** система показывает сообщение об ошибке с деталями

### Requirement: Выбор получателя
Система MUST предоставлять интерфейс выбора получателя из списка.

#### Scenario: Загрузка списка получателей
- **WHEN** пользователь нажимает «Отправить отчёт»
- **THEN** система загружает список получателей из БД портала

#### Scenario: Выбор получателя и канала
- **WHEN** пользователь выбрал получателя и канал
- **THEN** система отправляет PDF выбранному получателю через выбранный канал
