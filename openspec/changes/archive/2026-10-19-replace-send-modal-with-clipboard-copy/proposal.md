## Why

Текущий интерфейс отправки использует модальное окно с выбором канала (VK/Max/Email) и вводом адресата. Этот подход требует серверных вызовов для передачи PDF-файла и настройки мессенджеров. Для упрощения UX необходимо заменить отправку на копирование PDF-файла напрямую в буфер обмена браузера — без модального окна, без серверных вызовов.

## What Changes

- Удалить модальное окно отправки (`sendModal`) и весь связанный CSS/JS
- Заменить кнопку «Отправить отчёт» на кнопку «Копировать в буфер»
- Реализовать копирование PDF-файла в буфер через `navigator.clipboard.write()` с `ClipboardItem` и MIME type `application/pdf`
- Добавить визуальную обратную связь («Скопировано» / «Ошибка копирования»)
- Удалить неиспользуемые JS-функции: `openSendModal`, `closeSendModal`, `selectChannel`, `sendPdf`

## Capabilities

### New Capabilities

- `clipboard-copy`: Копирование PDF-файла в буфер обмена браузера через Clipboard API

### Modified Capabilities

- `pdf-creator`: требование «Система отправляет PDF в мессенджер» заменяется на «Система копирует PDF в буфер обмена»

## Impact

- **Файлы**: `app/views/index.php` — удаление модального окна, замена кнопки и JS-логики
- **Бэкенд**: API-эндпоинты `/api/send` и `/api/channels` больше не используются (оставлены на случай будущего возврата)
- **Зависимости**: новые зависимости отсутствуют, используется нативный Browser Clipboard API
